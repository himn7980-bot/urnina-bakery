# URNINA Bakery

GitHub-ready reconstruction of the URNINA Bakery website interface.

## Features
- Premium single-page bakery experience
- Scroll-driven cinematic hero
- English / Persian / Arabic
- RTL/LTR switching
- Creations, Story, Menu, Order, Contact sections
- Responsive desktop/mobile design
- Local visual assets included in `/assets`

## Run locally
Open `index.html` directly, or serve the folder with any static web server.

## Deployment
This is a static site and can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel or any static host.
